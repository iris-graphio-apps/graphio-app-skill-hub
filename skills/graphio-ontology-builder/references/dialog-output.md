# 대화 출력 규칙

사람에게 내는 대화 출력의 말과 길이를 정한다. 모든 단계와 세 모드(1차·`--fix`·`--verify`)가 따른다.

---

## 1. 말

- 한국어로 쓴다. 코드·식별자·파일 이름은 그대로 둔다
- 규칙 번호·결정 번호 같은 번호는 나오는 자리마다 뜻을 괄호로 함께 적는다. 예: DOC-12(매핑 없는 개념)

## 2. 숨길 것

- 해시 값과 스크립트 옵션 이름은 대화 출력에 쓰지 않는다. 파일에 남긴다. 예외는 5장 '다음 할 일'의 명령 예와 사람이 부를 옵션 안내(다시 연 ⑥의 `--diff` 등)다
- 표준 오류 원문과 예외 이름은 대화 출력에 내지 않는다. 실행 결과 파일 `detail`에만 둔다
- 다음 할 일은 5장의 실행 환경별 문장으로 적는다

## 3. 길이와 폭

| 항목 | 상한 |
|---|---|
| 한 줄 | 120칸(한글 한 글자는 2칸) |
| 표 | 4열 이하 |
| 한 번에 내는 글 | 30줄 안팎 |
| 목록 | 10건을 넘으면 건수와 파일 이름만 |

- 쓸 때는 짧게 줄을 나눈다. 폭·줄 수 상한은 시험 도구로 확인한다

## 4. 진행 표지 줄

- 단계를 시작할 때 접두어 `[진행 n/⑨]`를 붙인 한 줄을 낸다. 문구는 아래 표에서만 고른다

| 단계 | 문구 |
|---|---|
| ① | `[진행 ①/⑨] 참고 문서 역할 가리기 시작` |
| ② | `[진행 ②/⑨] 질문에서 값 모으기 시작` |
| ③ | `[진행 ③/⑨] 개념 정하기 시작 — 필수 CQ n건 기준` |
| ④ | `[진행 ④/⑨] 속성 정하기 시작` |
| ⑤ | `[진행 ⑤/⑨] 관계 정하기 시작` |
| ⑥ | `[진행 ⑥/⑨] 설계안 확인` |
| ⑦ | `[진행 ⑦/⑨] 데이터 구조·매핑 시작` |
| ⑧ | `[진행 ⑧/⑨] 설명 쓰고 서식으로 옮기기 시작` |
| ⑨ | `[진행 ⑨/⑨] 검사·리포트·판정 시작` |

## 5. 실행 환경별 행동 문장

| 스킬 출력 | Claude Code | 앱 | 일괄 |
|---|---|---|---|
| 멈춤 질문 파일 | `AskUserQuestion`으로 네 건씩 물음 | 기계가 읽을 수 있는 꼴로 넘김 | 파일을 남기고 `--answers`로 다시 부름 |
| 진행 표지 줄 | 대화 글 | 진행 표시 | 실행 로그 |
| 산출물 경로 | 경로 표시 | 내려받기 자리 | 파일 |
| 다음 할 일 | 문장과 명령 예 | 행동 코드 | 실행 결과 파일 |
