## 1. 개요

### 1.1 목적

- 온톨로지 정의 문서의 검사 결과를 기록함
- CQ 응답 여부, 서식 변환 여부, 매핑 컬럼의 의미 일치 여부를 확인함
- 조치 필요 여부는 판정하지 않음. 판정은 구조 판정 문서가 수행함
- 지적 사항이 있어도 곧 조치 대상은 아님. 규칙에 따라 비워 둔 항목도 지적으로 집계함

### 1.2 산출물 구성

- 온톨로지 설계 스킬 1회 수행 시 문서 4종이 생성됨. 이하 '스킬'은 이 설계를 수행한 도구를 가리킴

| 문서 | 내용 |
|---|---|
| 정의 문서 | 온톨로지와 속성-컬럼 매핑을 정해진 서식으로 기재한 문서. 이 리포트의 검사 대상이며 `graphio-ontology-converter`가 Graphio 정의 파일로 변환함 |
| 설계 리포트 | 설계 판단과 근거. CQ별 응답 경로 포함 |
| 검증 리포트 | 이 문서 |
| 구조 판정 | 검사 결과에 등급(Error·Warning·Info)을 부여하여 구조 확정 가능 여부를 판정한 문서 |

### 1.3 판정 기준

- 필수 CQ: 반드시 응답해야 하는 CQ. CQ 문서가 필수 등급을 밝혔으면 그 등급, 등급만 매겼으면 가장 높은 등급(스킬 판단), 등급이 없거나 높낮이를 가릴 수 없으면 전체 CQ로 봄
- 검사 결과값: No.3~6은 통과, 지적 n건, 미수행. No.1은 Error·Warning·Info 건수, No.2는 변환 여부와 규격 검사의 Error·Warning·Info 건수로 기재함. 변환에 실패하면 규격 검사는 미수행임
- 지적 건수 기준: No.3은 4.2절의 가이드 위반 행 수, No.4는 5절에서 응답 경로나 답이 빠진 CQ 수와 4.2절의 미사용 개념·속성 행 수, No.5는 통과 조건을 지키지 못한 CQ 수, No.6은 6절에서 일치가 아닌 행 수임
- 2절 검사 수행 결과 집계: No.1은 Error 0건, No.2는 변환 성공·규격 Error 0건이면 통과로 셈. Warning·Info는 통과로 세고 4.2절에 기재함
- 지적 목록(4.2절): 검사가 찾은 문제를 위치 1건당 1행으로 기재함. 칸은 규칙, 외부 코드, 위치, 문제 설명, 발생 경로, 조치 방안, 조치 주체, 참고 자료임
- 규칙 번호: 지적을 낸 검사 규칙의 번호임. 접두어가 검사를 가리킴(DOC 정의 문서 검사, CNV 서식 변환, SPC 규격 검사, GDE 가이드 준수 검사, CQS CQ-구조 정합성 검사·CQ 통과 조건 검사, MAP 매핑 의미 검사, INP 입력 문서 간 불일치). 규칙별 이름·등급·설명은 구조 판정 문서 1.3절(적용 규칙)에 있음
- 위치: 요소 종류와 이름, 정의 문서 줄 번호로 기재함. '(없음)'은 정의 문서에 그 요소가 없다는 뜻임. CQ 지적은 CQ 번호 뒤에 끊긴 곳을 '; '로 이어 기재함
- 서식 변환 검사는 규격 검사 결과를 Error·Warning·Info 3단계로 기재함

| 단계 | 정의 | 처리 |
|---|---|---|
| Error | Graphio 규격 위반. 반입해도 적용되지 않음 | 정의 문서 수정 후 재검사. 잔존 시 인수 불가 |
| Warning | 규격은 통과하나 의도 확인 필요 | 의도 여부 확인 결과 기재 |
| Info | 파일만으로 완료할 수 없어 대상 환경에서 마무리할 작업 | 7.1절에 조치 사항으로 등재 |

- CQ별 판정값

| 판정 | 정의 |
|---|---|
| 응답 가능 | 구조가 응답함 |
| 부분 응답 | 조건 또는 답의 일부가 누락됨. CQ 문서가 CQ 옆에 적은 조건 미충족 포함 |
| 응답 불가 | 응답 경로 없음 |

- 응답 가능이어도 조건이 붙는 경우 2가지: 데이터 미적재, 원천에 컬럼이 없어 매핑을 비운 경우. 구조 우선 설계이므로 응답 가능으로 판정하고 채워야 할 항목을 근거 칸에 기재함
- 매핑 판정값

| 판정 | 정의 |
|---|---|
| 일치 | 매핑 컬럼과 값의 뜻이 같음 |
| 대체 매핑 | 뜻이 다른 컬럼이 매핑되어 있음. 질의 결과가 틀림 |
| 의미 불일치 미매핑 | 비슷한 컬럼이 있으나 뜻이 달라 매핑하지 않음 |
| 원천 부재 미매핑 | 해당 뜻의 컬럼이 원천에 없어 매핑하지 않음. 설계 리포트 7.2절에 필요 컬럼으로 등재 |
| 원천 확인 필요 미매핑 | 해당 뜻의 컬럼이 원천에 있는지 몰라 매핑하지 않음. 설계 리포트 7.2절에 확인 사항으로 등재 |

- 매핑 뜻 판별 순서: 위에서부터 확인하여 처음 판별된 기준 1건의 번호를 6절 판정 근거 앞에 기재함

| 순서 | 판별 기준 |
|---|---|
| 1) | 스타일 가이드 또는 입력 문서의 결정 사항(두 말을 같은 대상으로 정해 둔 경우) |
| 2) | 용어 사전(값과 컬럼 이름이 같은 표제어 아래 있는지) |
| 3) | 원천 문서의 컬럼 설명 |
| 4) | 컬럼 이름이 가리키는 업무 절차 |

## 6. 매핑 컬럼 대조 결과

- CQ가 쓰는 값마다 대상 속성에 매핑한 컬럼의 뜻이 같은지 대조함
- 대체 매핑은 매핑이 채워져 있어 겉으로 드러나지 않으므로 값마다 1행씩 기재함
- 판정 근거 앞 번호는 1.3의 매핑 뜻 판별 순서임
- 관계를 거쳐 나오는 값은 그 관계의 조인 속성 쌍도 대조함. 양쪽 판정이 다르거나 한쪽이 대체 매핑이면 쪽마다 1행으로 기재함
- 대상 속성은 '개념 · 속성', 매핑 컬럼은 '데이터 구조.컬럼'으로 기재함. 한 행에 둘 이상을 기재하면 같은 차례로 쉼표로 이어 기재함
- 조치 방안은 대체 매핑 행에만 기재함
