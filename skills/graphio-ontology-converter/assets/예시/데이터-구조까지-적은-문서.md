# 보험계약 온톨로지 정의

> 네 절을 모두 쓴 문서다. 데이터 원천까지 정해져 Meta Type 과 Object Mapping 을
> 적었다.
>
> 눈여겨볼 것 넷 —
> 계약은 Meta Type 둘에서 온다. 기간계 원장과 신계약 시스템에 나뉘어 있어 그렇다.
> 약관은 `PARSING` 종류다. 문서를 파싱해 적재한 비정형 원천이라 그렇다.
> 가입자는 매핑이 없다. 개인정보 이관 승인을 기다리는 중이라 아직 잇지 않았다.
> 계약변경이력은 계약번호가 식별 속성이 아니다. 한 계약에 이력이 여러 건이라 그렇다.
