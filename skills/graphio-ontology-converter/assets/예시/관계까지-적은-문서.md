# 배송관리 온톨로지 정의

> 개념과 관계를 적은 표준 꼴이다. 방향은 화살표로 적었고, 색과 공개 줄을
> 필요한 개념에만 더했다. 데이터 원천은 아직 정하지 않아 Meta Type 절과
> Object Mapping 절을 두지 않았다.
>
> 눈여겨볼 것 셋 —
> 배송사고유형은 어느 관계에도 걸리지 않는다. 문서가 잇지 않았으니 그대로 옮겨진다.
> 배송기사는 상위 관리자를 속성으로만 적었다. 자기 참조 관계를 쓸 수 없기 때문이다.
> 배송품목의 주문번호는 식별 속성이 아니다. 한 주문에 품목이 여럿이라 그렇다.
