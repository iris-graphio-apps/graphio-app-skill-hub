# 맞춤법 점검 — 자주 틀리는 자리

국립국어원 한국어 어문 규범이 기준이다. 이 파일은 전체 규범이 아니라, 업무 문서에서
실제로 자주 틀리는 자리만 조항 번호와 함께 모은 것이다. 여기에 없는 것이 헷갈리면
아래 전문을 찾는다.

- 한글 맞춤법: https://korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0001
- 표준어 규정: https://korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0002
- 외래어 표기법: https://korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0003
- 국어의 로마자 표기법: https://korean.go.kr/kornorms/m/m_regltn.do?regltn_code=0004

## 띄어쓰기 (한글 맞춤법 제5장)

- **조사는 앞말에 붙인다** (제41항) — 꽃이, 꽃마저, 회의에서만.
- **의존명사는 띄운다** (제42항) — 할 **수** 있다, 아는 **것**, 그럴 **리**가 없다,
  떠난 **지** 3년(시간 경과의 '지'는 의존명사). 어미 '-ㄹ지'는 붙인다 — 올지 모른다.
- **만큼·대로·뿐** — 체언 뒤에서는 조사라 붙이고(너뿐, 약속대로), 용언의 관형형
  뒤에서는 의존명사라 띄운다(노력한 만큼, 시키는 대로, 웃을 뿐).
- **단위 명사는 띄운다** (제43항) — 차 한 **대**, 서버 두 **대**. 순서나 아라비아
  숫자와 어울리면 붙일 수 있다 — 3학년, 10개, 2시 30분.
- **수는 만 단위로 띄운다** (제44항) — 12억 3456만 7898.
- **보조 용언은 띄는 것이 원칙, 일부 붙임 허용** (제47항) — 꺼져 간다(원칙) /
  꺼져간다(허용). 한 문서에서는 한 방식으로.
- **안/않** — '안'은 부사라 띄우고(안 된다), '않'은 어간이라 어미와 붙는다(되지 않는다).
- **못하다** — 능력 부정은 붙이고(공부를 못한다), '못 + 동사'는 띄운다(못 간다).

## 렬·률과 열·율 (제11항 붙임 1)

모음이나 ㄴ 받침 뒤에서는 '열·율', 그 밖의 받침 뒤에서는 '렬·률'.

- 비율, 백분율, 실패율, 규율, 나열, 분열
- 법률, 확률, 성공률, 합격률, 행렬, 정렬

## 되·돼 (제35항 붙임 2)

'돼'는 '되어'의 준말이다. '되어'로 풀어 말이 되면 '돼', 안 되면 '되'.

- 됐다(되었다), 돼서(되어서), 안 돼(안 되어)
- 된다, 되고, 되니, 되면 — 자음 어미 앞은 '되'
- 판별이 급하면 '하/해'를 대입한다 — '하'가 어울리면 '되', '해'가 어울리면 '돼'.

## 던·든 (제56항)

- 지난 일은 '-던' — 좋던 시절, 쓰던 코드
- 선택은 '-든(지)' — 배포든 롤백이든, 가든지 말든지

## 어미의 소리 표기 (제53항)

- '-ㄹ게, -ㄹ지, -ㄹ수록'은 예사소리로 적는다 — 할게, 될지, 볼수록 (✗ 할께, 될찌)
- 의문 어미 '-ㄹ까, -ㄹ쏘냐'만 된소리다 — 할까

## 혼동하기 쉬운 말 (제57항 등)

| 갈리는 쌍 | 가르는 기준 |
|---|---|
| 로서 / 로써 | 자격·신분은 로서(담당자로서), 수단·도구는 로써(테스트로써 검증) |
| 맞히다 / 맞추다 | 정답을 맞히다, 일정을 맞추다 |
| 늘리다 / 늘이다 | 수량·크기는 늘리다(용량을 늘리다), 길이는 늘이다(줄을 늘이다) |
| 부치다 / 붙이다 | 보내다·힘이 달리다는 부치다, 맞닿게 하다는 붙이다(라벨을 붙이다) |
| 결재 / 결제 | 승인은 결재(품의 결재), 대금 지불은 결제(카드 결제) |
| 가르치다 / 가리키다 | 지식은 가르치다, 방향·대상은 가리키다 |
| 다르다 / 틀리다 | 같지 않으면 다르다, 맞지 않으면 틀리다 |
| 왠지 / 웬 | '왠지'(왜인지) 한 낱말뿐, 그 밖에는 웬 — 웬만하면, 웬일 |
| 며칠 | 항상 '며칠'이다 (✗ 몇일) — 제27항 붙임 2 |

굳은 오표기 — 금세(✗ 금새), 오랜만(✗ 오랫만), 역할(✗ 역활), 희한하다(✗ 희안하다),
어떡해(="어떻게 해", 서술) / 어떻게(부사).

## 사이시옷 (제30항)

순우리말이 든 합성어에서 앞말이 모음으로 끝나고 뒷소리가 된소리로 나거나 ㄴ이 덧나면
ㅅ을 받친다 — 바닷가, 나뭇잎, 아랫사람.

- **한자어끼리는 쓰지 않는다.** 예외는 여섯뿐 — 곳간, 셋방, 숫자, 찻간, 툇간, 횟수.
- **된소리·거센소리 앞에는 쓰지 않는다** — 위층, 위쪽, 뒤풀이 (✗ 윗층, 윗쪽).

## 표준어에서 자주 갈리는 것 (표준어 규정)

- **웃-/윗-/위-** (제12항) — 위아래 대립이 있으면 '윗-'(윗몸, 윗줄), 대립이 없으면
  '웃-'(웃어른, 웃돈), 된소리·거센소리 앞이면 '위-'(위층, 위쪽).
- **수-/숫-** (제7항) — 원칙은 '수-'(수놈, 수소). '숫-'은 숫양·숫염소·숫쥐 셋뿐.
  거센소리로 굳은 것은 그대로 — 수캐, 수탉, 수평아리.

## 외래어 표기 (외래어 표기법 제1장)

규칙 1이 음차 자체를 피하라고 하니 이 절이 필요한 자리는 적다. 음차가 불가피할 때는
이 원칙을 따른다.

- **된소리를 쓰지 않는다** (제4항) — 서비스(✗ 써비스), 파리(✗ 빠리)
- **받침은 ㄱ·ㄴ·ㄹ·ㅁ·ㅂ·ㅅ·ㅇ만** (제3항) — 커피숍(✗ 커피숖), 케이크(✗ 케잌)
- **굳어진 관용은 존중한다** (제5항) — 카메라, 라디오
- 심의로 굳은 표기 — 워크숍(✗ 워크샵), 콘텐츠(✗ 컨텐츠), 메시지(✗ 메세지),
  애플리케이션(✗ 어플리케이션)

## 로마자 표기 (국어의 로마자 표기법)

한국어 고유명사를 로마자로 적어야 할 때만 본다.

- 표준 발음대로 적는다 — 종로 Jongno, 신라 Silla
- 인명은 성-이름 순서, 이름은 붙여 쓴다 — Min Yongha
- 행정 구역 단위 앞에는 붙임표 — Chungcheongbuk-do

## 문장 부호 (한글 맞춤법 부록)

- **제목과 표어에는 마침표를 찍지 않는다.**
- **쌍점(:)은 앞말에 붙이고 뒷말과 띄운다** — 일시: 8월 21일.
- **직접 인용의 마침표는 따옴표 안에 찍는 것이 원칙, 생략도 허용** — "간다."라고 했다.
- **가운뎃점(·)은 짝을 이루는 열거에** — 보안·감사 요건.
